# ⚗️ Ethanol AI

Ethanol AI is a tool created within a research program called scientific initiation by researchers from UFSCar and DTU with funding from FAPESP. It is particularly useful for studying the behavior of different second-generation ethanol production processes when subjected to various operating conditions. This software implements hybrid machine learning models, previously trained using knowledge generated from previous research works at UFSCar and abroad, to predict the outcomes. Here, you can test different combinations of initial conditions, essentially finding the maximum possible yield for each situation.

## Run the App

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://ethanol-ai.streamlit.app/)

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## How the models are built

```
experiments ──► calibrated kinetic models ──► synthetic data ──► physics-structured neural networks ──► app
(data/raw)      (Arrhenius pretreatment,       (one dataset per    (ensemble; mass balance,
                 Angarita-type hydrolysis)      parameter sample)   monotonicity and bounds by design)
```

- **Pretreatment (hydrothermal):** global Arrhenius fit of the Rocha et al. (2017) reaction network,
  including the reactor heat-up, to the liquor composition measured at 180, 195 and 210 °C.
- **Enzymatic hydrolysis:** model of Angarita et al. (2015) recalibrated with the 8 experiments in this
  repository; structure chosen by leave-one-condition-out cross-validation.
- **Neural networks:** trained on data generated by the calibrated models, with the physics built into
  the output layer. An ensemble (one network per bootstrap parameter set) gives the uncertainty bands.
  Inference runs in NumPy, so the app does not need TensorFlow.

Full methodology (in Portuguese): [`docs/METODOLOGIA.md`](docs/METODOLOGIA.md).
Reproducing everything from the raw data: [`pipeline/README.md`](pipeline/README.md).

## Repository Structure

```
├── streamlit_app.py      # App entrypoint (deployed on Streamlit Community Cloud)
├── requirements.txt      # App dependencies (pinned, latest releases; Python 3.12 or 3.13)
├── requirements-research.txt  # + TensorFlow, matplotlib, openpyxl, pytest for the pipeline
├── ethanol_ai/           # Models package: kinetics, neural surrogates, operating ranges, optimization
├── pipeline/             # Reproducible steps 00–05: data → calibration → synthetic data → training → evaluation
├── models/               # Calibrated kinetic parameters (.json) and network weights (.npz)
├── data/
│   ├── raw/              # Original spreadsheets
│   ├── experimental/     # Cleaned experimental datasets used for calibration
│   └── synthetic/        # Generated training data (central member as .csv.gz)
├── reports/              # Calibration and evaluation reports with figures
├── tests/                # pytest: physics, fidelity to the kinetic models, app smoke tests
├── assets/style.css      # App styling (theme colors and fonts are in .streamlit/config.toml)
├── docs/                 # Methodology and references (article PDFs are not versioned)
└── research/             # Original notebooks of the scientific initiation (history, not used by the app)
```
